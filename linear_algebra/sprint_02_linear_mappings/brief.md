# Part 1: Geometric Consensus Brief — Linear Mappings & Matrix Composition

## 1. Geometric Action
A linear transformation $T: \mathbb{R}^2 \to \mathbb{R}^2$ is a continuous deformation of two-dimensional space that keeps coordinate grid lines straight, parallel, and evenly spaced, while pinning the origin strictly in place. Under the action of matrix $A$, the standard unit basis vectors $\hat{\imath} = [1, 0]^\top$ and $\hat{\jmath} = [0, 1]^\top$ transform into new column vectors $\mathbf{a}_1 = A\hat{\imath}$ and $\mathbf{a}_2 = A\hat{\jmath}$. Every point $\mathbf{x} = x\hat{\imath} + y\hat{\jmath}$ in the original plane moves to its transformed destination $A\mathbf{x} = x\mathbf{a}_1 + y\mathbf{a}_2$, riding the warped coordinate scaffolding.

When two linear mappings $A$ and $B$ are applied sequentially, matrix multiplication $BA$ represents geometric function composition: transformation $A$ deforms the space first, and transformation $B$ acts on the resulting deformed grid. Because spatial operations like shears and rotations distort directional axes, changing the order of execution generally alters the final destination of basis vectors, geometrically proving that $BA \neq AB$.

## 2. Geometric Invariants
- **Origin Anchor**: The origin is a universal fixed point: $A\mathbf{0} = \mathbf{0}$. Any mapping where $f(\mathbf{0}) \neq \mathbf{0}$ is an affine translation, not a linear mapping.
- **Parallel Line Preservation**: Parallel lines share identical tangent vectors $\mathbf{v}$. Under $A$, their images share direction $A\mathbf{v}$, remaining strictly parallel (or collapsing along the same line if $A\mathbf{v} \neq \mathbf{0}$).
- **Uniform Spacing Invariant**: Equidistant points along any line $\mathbf{x}_k = \mathbf{p} + k \Delta t \mathbf{v}$ map to $A\mathbf{x}_k = A\mathbf{p} + k \Delta t A\mathbf{v}$. Consecutive mapped displacements $\Delta t A\mathbf{v}$ are identical, preserving uniform interval spacing.
- **Determinant Area Scaling**: Signed area scales globally by $|\det(A)|$. For compositions, area scaling is commutative: $\det(BA) = \det(B)\det(A) = \det(AB)$, even when the geometric mappings themselves do not commute.

## 4. Dual Bridge
### Frontier ML: Linear Layers, Attention Projections & Operator Fusing
In deep neural architectures, linear transformation layers perform feature space projections $\mathbf{h} = W\mathbf{x}$. In Transformer Multi-Head Attention, token representations $X \in \mathbb{R}^{T \times d_{\text{model}}}$ undergo learned linear mappings into queries and keys:
$$Q = X W_Q, \quad K = X W_K \implies Q K^\top = X (W_Q W_K^\top) X^\top$$
The attention logits are generated by the composed bilinear operator $M = W_Q W_K^\top \in \mathbb{R}^{d_{\text{model}} \times d_{\text{model}}}$. In production inference pipelines, sequential linear operators (e.g. Convolution/Linear followed by Batch Normalization) are composed and folded into a single weight matrix $W_{\text{fused}} = \text{diag}(\gamma / \sqrt{\sigma^2 + \epsilon}) W$, eliminating intermediate memory allocations.

### GATE CS/DA Shortcut: Matrix Multiplication Invariants & Operator Associativity
While matrix multiplication is non-commutative ($AB \neq BA$), it is strictly associative: $(AB)C = A(BC)$. Dynamic Programming optimizes Matrix Chain Multiplication by finding the parenthesization that minimizes scalar operations in $\mathcal{O}(n^3)$ time. Furthermore, two vital scalar invariants bypass coordinate dependence:
1. **Determinant Multiplicativity**: $\det(AB) = \det(A)\det(B) = \det(BA)$.
2. **Cyclic Trace Invariance**: $\text{Tr}(AB) = \text{Tr}(BA)$ for rectangular compatible dimensions $A \in \mathbb{R}^{m \times n}, B \in \mathbb{R}^{n \times m}$.
