# Sprint 1: Vectors, Linear Combinations & Span

## Overview & Curriculum Context

Sprint 1 establishes the geometric and algebraic foundation of the `math_cs` linear algebra animation curriculum. It transforms abstract definitions of vectors, vector spaces, and linear spans into intuitive, dynamic geometric mechanisms following the 3Blue1Brown visual standard.

Linear algebra is not merely a collection of matrix manipulations; it is the geometry of vector spaces under continuous linear actions. This module grounds core concepts across three canonical textbooks:
- **Mathematics for Machine Learning (MML)**: Vector spaces, subspaces, linear independence, generating sets, and basis (§2.4–2.6).
- **Introduction to Applied Linear Algebra (VMLS - Boyd & Vandenberghe)**: Linear, affine, and convex combinations; linear independence and the Independence-Dimension Inequality (Ch. 1 & 5).
- **Immersive Linear Algebra (ILA - Ström, Åström et al.)**: Coordinate-free directed segments, vector arithmetic, and 2D/3D span generation (Ch. 1–2).

## Scene Manifest & Architecture

The production script `scene_vectors_span.py` provides five modular `Scene` classes designed for independent rendering or cohesive end-to-end playback:

```
scene_vectors_span.py
├── VectorSpanBase (Shared utilities, HUD paneling, color palettes, coordinate planes)
├── Act1SpatialPuzzle (~18s)         [Scene]
├── Act2DynamicDeformation (~20s)   [Scene]
├── Act3AlgebraicMorph (~18s)       [Scene]
├── Act4DegenerateStressTest (~22s) [Scene]
└── VectorSpanScene (~78s)          [Master Combined Scene]
```

### Scene Descriptions
1. **`Act1SpatialPuzzle`**:
   - Poses the fundamental reachability challenge: Can two fixed arrows $\mathbf{v}_1 = [2, 1]^\top$ and $\mathbf{v}_2 = [-1, 2]^\top$ reach arbitrary target point $\mathbf{b} = [3, 4]^\top$?
   - Demonstrates naive failure ($1\mathbf{v}_1 + 1\mathbf{v}_2 \ne \mathbf{b}$) followed by exact parallelogram completion ($2\mathbf{v}_1 + 1\mathbf{v}_2 = \mathbf{b}$).
2. **`Act2DynamicDeformation`**:
   - Uses `ValueTracker` instances to continuously sweep scalar coefficients $c_1$ and $c_2$.
   - Shows line of action generation (1D line), parallel translation (affine line), and full oblique lattice expansion (2D plane).
3. **`Act3AlgebraicMorph`**:
   - Morphs symbolic LaTeX equation $\mathbf{v} = c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2$ directly into vector arrows.
   - Transitions to formal set-builder span notation and unleashes a continuous translucent purple sheet washing over $\mathbb{R}^2$.
4. **`Act4DegenerateStressTest`**:
   - Rotates $\mathbf{v}_2$ into collinear alignment with $\mathbf{v}_1$ ($\mathbf{v}_2 = 2 \mathbf{v}_1$).
   - Visually collapses the 2D sheet into a 1D line; tests an off-line target $\mathbf{b}_{\text{unreachable}} = [1, 4]^\top$.
   - Displays GATE CS/DA Rouché-Capelli rank failure ($\text{rank}(A) = 1 \ne \text{rank}([A \mid \mathbf{b}]) = 2$).
   - Contracts vectors to zero, illustrating the 0D trivial subspace $\{\mathbf{0}\}$.
5. **`VectorSpanScene`**:
   - The master comprehensive narrative stringing Acts 1 through 4 together with seamless camera and HUD transitions.

## Mathematical Invariants & Verification Checklist

All code and companion texts conform to automated testing standards in `tests/test_sprint01_invariants.py`:

- [x] **Basis Invertibility**: $\det([\mathbf{v}_1 \mid \mathbf{v}_2]) = 2(2) - 1(-1) = 5 \ne 0 \implies \text{Full Rank } 2$.
- [x] **Reachability Consistency**: $A \begin{bmatrix} 2 \\ 1 \end{bmatrix} = \begin{bmatrix} 3 \\ 4 \end{bmatrix}$ solved exactly by NumPy.
- [x] **Collinear Rank Collapse**: $\mathbf{v}_2 = 2\mathbf{v}_1 \implies \text{rank}([\mathbf{v}_1 \mid 2\mathbf{v}_1]) = 1$.
- [x] **Inconsistent System Detection**: $\text{rank}(A) = 1 < \text{rank}([A \mid \mathbf{b}_{\text{unreachable}}]) = 2 \implies 0$ solutions.
- [x] **Origin Invariance**: $\mathbf{0} \in \text{span}(S)$ holds unconditionally for all vector sets $S$.
- [x] **Convex Hull Boundedness**: $\sum \alpha_j \mathbf{v}_j$ with $\alpha_j \ge 0, \sum \alpha_j = 1$ is confined to the simplex.
